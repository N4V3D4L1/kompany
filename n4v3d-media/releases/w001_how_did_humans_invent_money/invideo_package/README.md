# InVideo import package

This is a **manual** export for InVideo AI's supported interface: paste the script, use the scene prompts and storyboard frames as references, and follow the narration/music/editing notes.

InVideo also offers an official MCP server (mcp.invideo.io/mcp) for AI agents; it requires a paid InVideo seat and account authorisation and is **not connected or tested** in this system yet. The local pipeline does not depend on it.
